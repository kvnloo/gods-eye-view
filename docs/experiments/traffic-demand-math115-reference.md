# GEV × OpenAI Math #115 — bounded demand ensemble reference

## Purpose

Synthetic fixed-margin origin/destination scenarios for an external traffic model.
This **does not** sample the conditional distribution of real-world traffic, does
**not** use the scalable algorithm proposed in [OpenAI math family 115](https://github.com/openai/math/blob/main/lean/docs/115.md), and must never be treated as observed demand, an access finding, a forecast, or a signal-control instruction.

Exactly enumerate only a 2×2 fixture of ≤64 feasible matrices. The reference
family can test a future generalized sampler and create reproducible inputs for
the existing GEV fork [scenario comparator #186](https://github.com/kvnloo/gods-eye-view/pull/186).

### Example

`rows=[3,2]`, `columns=[2,3]` has three feasible integer matrices:

```
[[0,3],[2,0]]
[[1,2],[1,1]]
[[2,1],[0,2]]
```

For EACH hypothetical demand matrix, an external SUMO experiment could run
fixed-time and adaptive control plans with identical network, demand revision,
source revision, engine/version, time interval, and random seed. GEV's existing
`compareTrafficScenarioRuns()` compares matched pairs, never unmatched scenarios.

The user-facing result would be a *sensitivity display*: how plan A vs plan B
behaves over several equally bounded-but-not-necessarily-equally-likely demand
assumptions. Nothing here estimates scenario probabilities, physical realism,
traffic volumes, congestion reduction, or human welfare.
